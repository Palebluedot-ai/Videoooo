# Videoooo

Chao 学习 AI video 的个人学习仓：一边记学习笔记，一边跟着写代码实验。本机自用，不是产品。

## 怎么用这个仓

| 你想干什么 | 去哪 |
|---|---|
| 看项目全貌 | 浏览器打开 `dashboard.html` |
| 看现在在学什么 | `docs/state/progress.yaml` |
| 看学习笔记 | `docs/notes/` |
| 跑代码实验 | `docs/experiments/` |
| 随手记想法 | `thoughts-and-ideas.md` 的 📥速记区 |
| 看 AI 该守什么规矩 | `AGENTS.md` |

## 四个口令（对 AI 说）

- 「**整理想法**」→ 把速记区归类成文
- 「**更新仪表盘**」→ 从真相源重绘 `dashboard.html`
- 「**agent-on 结账**」→ 方法论沉淀回流
- 「**agent-on 升级**」→ bump agent-on 版本 pin

## 环境

Python 包管理一律 `uv`，不用 pip：

```
uv venv && uv pip install -r requirements.txt
```
