# ROADMAP — 加密晨报 AI 动画（总框架 v1.1）

> **这是本项目的主框架，我们不断完善的就是这份文件。** 每次迭代改这里，版本号 +1。
> 组织原则：**以产出物倒推**——每个里程碑用「做出什么东西」定义，不用「学了什么」定义。学习发生在做的过程里，知识由 AI 在每一步按需注入。
> 执行原则：**验收一律归 AI**（机器检查 AI 跑，质量判定 AI 做并讲解）；你的节奏是每天一点，做多少算多少，断了接着来。
> ❓ = 待你拍板的框架点，见文末清单。

---

## 一、最后的输出是什么（北极星）

**每天早上❓8:00，自动产出并发送一集《加密晨报》动画：**

| 维度 | 定义 |
|---|---|
| 形态 | ❓竖屏 1080×1920，约 60 秒 |
| 主角 | 漫画风格固定虚拟主播——**每天是同一个人** |
| 内容结构 | ❓开场问好 → 大盘一句话 → 三个币价卡 → 一条要闻 → 收尾 |
| 分工铁律 | **画面 = AI 生成；数字/文字 = 代码叠加**（绝不让模型写字）；配音 = TTS；字幕 = 自动对齐 |
| 数据 | 行情 API 实时取数——事实绝不由模型生成 |
| 发送 | ❓Telegram |
| 质量线 | 每集过 12 破绽检查（AI 跑）+ 主播一致性检查 |

**双重产出**：这个系统本身，和做出它的过程中长出来的**能力**（后者才是你说的真正目标）。

## 二、里程碑链（M1 → M5，每个以产出物定义）

```
M1 主播诞生 → M2 第一集样片(全手工) → M3 生产手册 → M4 一条命令出一集 → M5 日更系统
```

### M1 · 主播诞生
| | |
|---|---|
| **产出物** | ① 主播设定集：turnaround 五视图 + HEX 色标 + 「杜绝写实化」注释 ② 演播室/场景图 2–3 张 |
| **完成判据**（AI 验） | 拿设定集里任意一张视图去生成新图，**出来的还是那个主播** |
| **投入** | 几天 · 几块钱（出图） |
| **前置决定** | ❓主播形象方向（见文末） |
| **对应能力** | L0 前期设定 + L3 一致性的资产源头 |

### M2 · 第一集样片（全手工）—— 最大的里程碑
| | |
|---|---|
| **产出物** | **一集完整晨报动画**，用当天真实行情，手工走完全流程：beat map → 分镜表（过校验器）→ 生成片段 → 拼接 → TTS 配音 → 字幕 → 数据叠加 |
| **完成判据**（AI 验） | ① 你愿意发给一个朋友看 ② 12 破绽检查通过 ③ 主播与 M1 设定集一致 |
| **投入** | 1–2 周 · 几十到一两百元（60 秒成片 × 5–10 倍生成量的抽卡） |
| **意义** | **做完它，「能力」就有了底**——后面全是提效，不再是从零学 |
| **对应能力** | L0–L2 全用上 + L6 入门（剪辑/配音/节奏第一次实操） |

### M3 · 从样片到生产手册
| | |
|---|---|
| **产出物** | 「每集生产手册」：固定分镜模板（每集只换数据和新闻）、prompt 模板库、可复用素材清单（片头/转场/演播室底图） |
| **完成判据** | 照手册做第二集，**耗时比第一集降一半以上**（AI 计时对比） |
| **投入** | 几天 · 几十元 |
| **对应能力** | 把 M2 的一次性成功变成可重复流程——工业化的第一步 |

### M4 · 一条命令出一集
| | |
|---|---|
| **产出物** | 管线脚本：行情 API 取数 → 生成播报稿 → 调视频/TTS API → 合成字幕与数据层 → 成片 |
| **完成判据** | `uv run make_episode.py` 从数据到成片，中途不需要手动干预（**挑片除外**——挑片数据攒起来，是 L5 自动筛选的训练集） |
| **投入** | 1–2 周（**这是你「学写代码」的主战场**）|
| **对应能力** | L4 管线。参考架构现成：claude-video-kit（TTS→词级字幕→时间轴→竖屏渲染）+ OpenMontage avatar-spokesperson 管线 |

### M5 · 日更系统
| | |
|---|---|
| **产出物** | 定时任务 + 自动发送（❓渠道） |
| **完成判据** | **连续 7 天**每天早上自动收到当天的晨报 |
| **投入** | 几天 |
| **⚠️ 闸** | 触发暂停项 P1 复审（自动发送 = 常驻服务），到时一起过 |

## 三、贯穿三条线（不占里程碑，随行）

| 线 | 内容 | 谁负责 |
|---|---|---|
| **质量线** | 每个产出过 12 破绽检查 + 一致性检查 + 分镜校验器 | AI 跑并讲解 |
| **知识线** | 术语、镜头语言、五段式……在做每一步时按需讲，不单独设「学习阶段」 | AI 注入 |
| **台账线** | 每次生成记「花费/抽了几次/选没选中」→ M4 之后变成自动筛选的训练数据 | AI 记 |
