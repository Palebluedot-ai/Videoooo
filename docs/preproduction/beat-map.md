# Beat Map —— 剧本层模板

> 规范来源：OpenMontage `script-director.md`（逐字读取）
> 强制结构 `Hook → Escalation → Reveal → Landing`；长片可加**一个** midpoint turn，
> 但 "should not become essay-like in complexity"。

## dialogue_selects
从素材语音里开采四类：strong standalone lines / emotional phrases / concise declarations / reveal phrases
> 没有可用台词时走 title-led 或 narration-led，**并在这里写明原因**。

## title_card_copy
