## 一、五段式结构（顺序不可乱）

### ① 核心主题 —— 一行风格标签，`|` 分隔
> 3–6 个标签，从**画面类型 → 题材 → 美学风格**层层递进

原文示例：
```
写实暗黑特摄 | BLACK SUN美学 | 破碎肉身 | 战损变身 | 末日战场
原子朋克 | 末日丧尸 | 电影级质感 | 超写实 | 杜绝游戏CG感
写实科技感 | 科幻机甲 | 磅礴史诗 | 重工业机械美学 | 真人演绎
```
注意最后一个标签常是**否定式**（「杜绝游戏CG感」）——先划掉不要的。

### ② 人物与基础设定 —— 三行
- **面部**：`参照上传图片，五官、脸型、发型百分百还原，杜绝美化`
- **服装**：强调**质地**——`哑光黑色皮质长风衣，金属腰带为哑光质地`
- **场景**：写**动态**环境，不是静态背景

### ③ 氛围与画质 —— 模拟真实摄影机
**不要写「电影感 / 4K / 高细节」**——AI 锚不住。写**具体器材型号**：
```
IMAX胶片摄影机，搭配Panavision C系列镜头（焦段35mm，光圈f4）   ← 史诗感
索尼威尼斯电影机 + 佳能K-35系列镜头                              ← 暗调赛博
```

### ④ 运镜规则 —— 三行
- **单镜头设定**：`一镜到底，无剪辑`（或多镜头方案）
- **角度**：`开场仰拍，人物半身左侧面30度…变身完成后环绕至人物右侧面俯拍`
- **呼吸感**（必备行）：`手持拍摄，全程保持极其轻微的、如呼吸般的镜头浮动，增强临场感`

**术语库**：
| 维度 | 词 |
|---|---|
| 景别 | 极近距离特写 / 特写 / 近景 / 中景 / 全景 / 大全景 |
| 角度 | 仰拍 / 俯拍 / 平视 / 过肩镜头 / 高空垂直俯拍 |
| 运动 | 极缓向前推进 / 环绕 / 跟随运动拍摄 / FPV模式 |
| 节奏 | 极缓 / 匀速 / 突然 / 应激性0.1秒微颤 |

### ⑤ 分镜（时间轴）—— 两种写法

**写法 A · 按秒切片**（单镜头一镜到底）——每段**动作 + 镜头 + 特效**三件套：
```
0-3秒 · [阶段名]
动作：主角略微低头，目光锁定腰带，脊背紧绷
镜头：极缓向前推进，捕捉身体因呼吸产生的微幅起伏
特效：整颗眼球骤然亮起白金色光芒，眼眶周围皲裂
```

**写法 B · 按镜头切片**（多镜头剪辑）——四件套：
```
分镜一：
景别：[近景/中景/全景]
构图：[画面布局]
运镜手法：[镜头运动]
画面内容：[具体发生什么]
```

**声音行**（必备）：`声音：无配乐，仅保留现场同期声`

## 二、三条反直觉原则（速查卡原文）

1. **「图片质量不高就别喂参考图」** —— AI 会模仿**画风**而不是模仿**设计**
2. **「描述缺陷 = 描述真实」** —— 每段落至少 2 处瑕疵；`保留轻微面部瑕疵`、`面部伤口，纱布，血渍保持一致`。**真实感来自瑕疵，「杜绝美化」要写死**
3. **「抽卡是常态」** —— 同样提示词生成两次也会显著不同

## 三、角色一致性：最值钱的一招是**设计层绕开**

技术层做法（写死在提示词里）：
> `参照上传图片，百分百还原，杜绝美化。面部伤口，纱布，血渍保持一致`

**但 Mx-Shell 真正的解法在设计层**：把主角设计成**机器人，用像素风表情屏当五官**——
> 这样「更容易维持稳定的视觉特征」，避免真实人脸「隔几个镜头就可能变形走样」

**→ 这是全篇最该学的一条：不要用提示词去硬扛模型的弱点，用美术设定绕开它。**
类比编程：这是**改需求规避不可靠依赖**，不是**给不可靠依赖写重试**。

## 四、抽卡预算（速查卡原文数字）

| 项 | 数字 |
|---|---|
| 简单镜头 | 2–3 次重投 |
| 困难镜头 | 20+ 次重投 |
| 项目级 | **生成量 ≈ 成片的 5–10 倍** |
| 原文 | 「200+ 个镜头，每个少则两三次、多则 20+ 次才能挑出能用的」 |

**→ 一部 3 分钟片子 ≈ 200 个镜头 × 平均 5 次 = 1000+ 个文件要管。这是工程问题，正是 Claude Code 的活。**

## 五、各模型平台差异与坑（repo README 表格）

| 模型 | 单镜头上限 | 负向提示词 | IP 过滤 | 坑 |

| **Seedance 2.0**（Mx-Shell 主力） | ~10–15 秒 | 部分 | 严格 | **原生同期音是杀手锏**；豆包 App 锁死 5/10 秒预设，完整 4–15 秒只在即梦/Dreamina 网页版 |
| Veo 3/3.1 | 8 秒（可扩展至 ~148 秒） | 有 | 严格 | **别用命令式 no/don't**，改描述性短语 `extra limbs, glitch morphs` |
| 可灵 2.x/3.0 | 5–15 秒 | 有 | 极严格 | 违禁词过滤「臭名昭著地过敏」，一个无害词毙掉整条 |
| 海螺 2.3 | ~6–10 秒 | 有 | 中等 | 分辨率与时长反向权衡 |
| Wan 万相 2.x | ~3–15 秒 | 有 | **宽松** | **可自托管**；偏中文优化 |
| Sora 2 Pro | ~25 秒 | 无字段 | 严格 | 拦「视觉神似」不只是名词 |
| Runway Gen-4 | 5–10 秒 | **无** | 严格 | **负向提示词有害**——写 `no distortion` 反而召唤畸形 |

## 六、交付前自检（21 项检查表的核心几条）

- [ ] 摄影机型号具体（**禁空泛词**：电影感 / 4K / 高细节）
- [ ] 运镜有**物理反馈**描述（如「呼吸般浮动」）
- [ ] 场景细节 vs 形容词比例——细节占优
- [ ] 每段落 ≥2 处瑕疵
- [ ] **结尾留白而非炫技**

Mx-Shell 原文（片尾设计）：
> 「没有台词。没有爆炸。没有光芒万丈。只有身穿不完整战衣的人站在原地」

他给新手的话：
> 「先试试自己有没有这个天赋」「对创作来说，设备不是重要的。想法才是最重要的。」
