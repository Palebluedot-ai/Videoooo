01 / 学习法这个领域没有教科书，所以先定怎么学

调研结论摆在那里：没有任何机构发布过能力判据或卡点数据，7 条这类主张被 3 票否决。把 AI 视频当工程学系统论述的东西还不存在。这意味着你的学习方式必须和「学一门有教科书的学科」不同。

有教科书的学科AI 视频（现在）
路径读教材 → 做习题 → 考试没教材、没习题集、没考官
判据权威给自己从质量 rubric 反向构造
大纲跟着走自己搭（就是第 03 节那份）
所以学习法的核心不是「找到好教程」，是建立自己的判据与反馈回路。这也是为什么这一页到处标着证据等级——你在学一个没人给标准答案的东西，标注能力比记忆能力重要。

学习循环：一个可重复的最小单元

①读规范只读当前这一小块。读完能复述判据，否则重读
②拆最小单元拆到 30 分钟内能验一次。做不到就继续拆
③做一次必须有产出物。只读不产出 = 没学
④用判据验机器判据 > 清单 > 自我感觉
⑤记认知差「我原以为 X，实际是 Y」。没有认知差 = 这轮白做
⑤ 是最容易被跳过、也最值钱的一步。认知差是学习真正发生的地方。攒够 20 条，你就有了这个领域里别人没有的东西——因为没人公开发过。

⭐ 「先不训练」的正确形态：反推法

不想动手生成是对的——但纯读会失效，因为这套东西的判据全是产出物。解法是输入端学习：拿别人的成片当教材，对着规范反推。不生成一帧，不花一分钱，练的是真能力。

挑一个镜头（5–15 秒）
  → 对着 5-Aspect 五维，反推它的分镜表怎么写
  → 填进 shots.yaml，跑校验器
  → 跟原片对照：我推出来的，和它实际呈现的，差在哪
为什么最有效不消耗生成额度，没有抽卡随机性干扰 · 有标准答案（原片就在那，推错一眼看得出）· 直接练 L0 而 L0 是后面每级的输入 · 一个镜头 15 分钟，符合 30 分钟回路
三个梯度易 静止或单一运镜 · 中 主体运动 + 运镜（最常推错：分不清主体动还是镜头动）· 难 多主体 + 景深变化 + 有 overlay
关于「拉片」的一处更正最早那版（错）现在这版（对）
身份过关测试——考你能不能看出破绽学习手段——用成片当教材反推规范
产出一张打分表一张分镜表（可机器校验）
学到什么「这条片子有问题」「这个效果是怎么写出来的」
看破绽是诊断，反推是学习。12 破绽表的正确位置是 L1 起的验收 QC 门（第 05 节）。

02 / 地基决定学习顺序的那条线

已验证 3-0VBench-2.0 区分 superficial faithfulness（逐帧美感、时序一致、基本 prompt 遵循——论文原话「approaching saturation」）与 intrinsic faithfulness（物理律、常识、解剖、构图完整）。关键是：intrinsic 不是全面失败，是特定维度崩溃。

Commonsense / Instance Preservation常识 · 物体保持
92–94%
Human Anatomy人体解剖
86–88%
Dynamic Spatial Relationship动态空间关系（走位、相对位置变化）
19–21%
Dynamic Attribute Change动态属性变化（边走边变色、逐渐融化）
8–24%
Complex Plot复杂情节
9–11%
vintage 警告：这批数字来自 VBench-2.0 Table II，对应 2025-03 那批模型（Sora / Kling / HunyuanVideo / CogVideoX）。不可当作当前值——当前榜单接口返回 401，取不到。用它判断「哪类维度难」，不要用它判断「今天某个模型多少分」。
模型已饱和逐帧美感、时序一致、基本 prompt 遵循、常识、物体保持——不是你的学习内容，别花时间。
模型崩溃动态空间关系、复杂情节、动态属性变化——这才是你的手艺所在，而且必须靠「改设计绕开」，不是靠「把 prompt 写得更好」。

这就是构造阶梯的原则，也是全文的方法核心。

04 / SOP工业级怎么做：流水线 · 分镜 · 三视图

源文件逐字读取下面这套不是我编的流程——来自 OpenMontage（48.9k★）的 cinematic 流水线源文件，10 个 director 角色。工业级的意思不是「画得好」，是每个环节有交付物、有验收、有闸。

主流水线：8 阶段

每阶段最多返工 3 每对阶段回退 1 全流程回退 3 墙钟上限 12 min 预算告警 90%
静默降级禁令（原文）："If Remotion or clip generation breaks a motion-led brief, stop and bubble the issue to the user instead of quietly switching mediums."
合成阶段同理——"Silent swap to another runtime is a CRITICAL governance violation." 工具跑不动就上报，不许偷偷换便宜路子交差。

剧本层：beat map 四件套

Hook → Escalation → Reveal → Landing ——长片可加一个 midpoint turn，但 "should not become essay-like"。

必填字段：beat_map · dialogue_selects · title_card_copy · music_turns · silence_windows

silence_windows 是必填字段——沉默被当作设计对象管理，不是「没声音的地方」。
标题卡标准（原文）："fewer words, more contrast, more whitespace, more timing precision"

⭐ 分镜层：5-Aspect Shot Breakdown（强制）

scene director 的职责原文：决定 "how each cinematic beat will look and transition. This is where mood becomes a visual plan." 每个 beat——尤其 hero frames——五维必须全部写明。

1
Subject 主体
type + key visual attributes；若有多个主体，必须写清怎么区分
2
Subject Motion 主体运动
actions in temporal order（按时间顺序）；主体↔物体 / 主体↔主体的交互
3
Scene 场景
overlays（单独列！）+ POV + setting + time of day + scene dynamics
4
Spatial Framing 空间构图
shot size + position-in-frame + depth（FG/MG/BG） + camera-height-relative
5
Camera 相机
书写顺序被规定死：playback speed → lens distortion → height → angle → focus/DoF → steadiness → movement
贴墙上那句（原文）："Vague hero-frame specs are the single most common failure mode."

Overlays 规则：字幕/图形 "NOT part of the scene's foreground/midground/background depth axis. List them separately in scene metadata." 混进景深轴 = 模型会试着把字幕当场景里的实物渲染。

转场克制：只用一个 small set——hard cut / fade / dissolve / restrained push-in。
5-Aspect 分镜五段式提示词
是什么规划层——想清楚这个镜头是什么表达层——把它翻译给模型
产出scene_plan（人读的分镜表）prompt 文本（模型读的）
何时用写 prompt 之前规划完之后
弯路警告：直接上五段式写 prompt = 跳过规划层。想都没想清楚，翻译得再漂亮也是空的。

完整 character sheet 六件套——它是沟通契约，不是画着好看。产出于前期，贯穿 concept → final frame，使用者是分镜师、动画师、角色设计、导演。

Turnaround 标准角度：

正面3⁄4 前侧面 profile3⁄4 后背面

AI 时代怎么做——拿一张角色参考图，用这条 prompt（原样引用）：

Create a four-panel turnaround for this man to show his frontal,
his right side, his left side and his back, in a white and grey background.
为什么这么写有效：必须用 "turnaround" 这个词（行业标准的正投影术语，模型认它）· 明确列出每一个视图，别指望模型自己补全 · 白灰背景制作友好。
这就是 L3 一致性的源头。参考图条件化喂进去的应该是 turnaround，不是随手一张图——一张正面照只锁住正面，模型转侧面就自由发挥。
我的推论「turnaround 优于单张参考图」逻辑成立（锁 360° vs 锁一个面），但没找到直接实证——这是你 L3 该亲手验的第一件事。

资产层：三条防烧钱规则

Sample-before-batch原文："Before batch-generating support assets, produce one sample of each expensive generated type and show the user."
Provider disclosure出样之前就告知："exactly which generation path will be used: tool, provider, model or variant, generation mode, why it was selected"
Rights notesmetadata 必须含 rights_notes 做出处留痕 —— 你的仓是 public 的，这条是硬需求

合成层：保护项与验收

保护：音频要留 quiet moments / impact moments / clear dialogue / controlled swells；调色与锐化不能伤脸和字；letterbox、24fps 意图、重调色只在真的帮到片子时才用。

验收四点：opening frame · reveal beat · final landing · subtitle readability

05 / 验收表「一眼假」的 12 个破绽 · 每级都过

这不是一个学习阶段，是贯穿全程的 QC 门。原本它是 L0（拉片找破绽）——那是诊断不是方法，已降级：L1 起每一级交付时都过一遍这张表。工业界的 QC gate 本来就贯穿全程，不是入门考试。

学术表述是 superficial / intrinsic 之分，实操版是这 12 条。红边落在 intrinsic 一侧（物理 / 解剖，模型崩溃）黄边落在 superficial 一侧（后期可修）。两套框架对得上，互为印证。

01手部变形暂停数手指——4 根 / 6 根 / 帧间变化。绕：选不露手的镜头，或构图让手出画
02切镜后背景物理不一致云位置、阴影、光向在两镜间是否守恒。绕：人工控制多镜背景
03平板恐怖谷打光各环境都是「晴朗午后」扩散光、无硬阴影。修：显式给光位与硬阴影
04过饱和合成色草太绿、肤色偏橙、天空均匀饱和无渐变。修：后期压到真实传感器水平
05运动过于顺滑像飞行模拟器一样线性稳定，缺真实微抖。修：加微抖 = 五段式的「呼吸感」行
06口型音画不同步看 p / b / m 双唇音时嘴有没有闭合。修：调优的语音克隆
07镜面反射崩坏反射物错位、角度错、直接消失。绕：画面里别放镜面
08画面内文字变乱码路牌书封是否帧间一致可读。绕：场景里最小化文字
09背景群演单腿走路步态是否真的左-右-左。绕：剔除背景密集的镜头
10纹理重复平铺草地砖墙沙滩有无可见重复块。修：手动处理
11克隆声无呼吸真人每 5–10 秒换气一次，AI 常不换。修：带韵律模型的 TTS
12TTS 平台调有无重音起伏、列举加速、停顿。修：同上
