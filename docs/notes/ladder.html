AI 视频能力阶梯

一份可以一级一级打勾的学习路径。地基是三块经过对抗验证的学术证据，阶梯本身是构造的——每一处的证据等级都标出来了，你可以推翻任何一级。

2026-08-20 2 轮 deep-research 212 agents 验 50 条 · 确认 24 · 否 25
本轮最重要的结果是一个否定结论

你要的那种「能力阶梯」，公开资料里不存在。

证据不是「没搜到」，而是这类主张被系统性否决——被 3 票否掉的 14 条里有 7 条恰好全是「某机构课程发布了能力判据 / 硬门禁 / 能力分解」这一类（Comfy Compositing 三层门禁 0-3、Curious Refuge 九阶段 0-3、NYU Tisch 三能力域 0-3、Full Sail 三模块 0-3×3……）。唯一被逐字核实的机构大纲是生产流程顺序，零能力判据、零关卡考核、零卡点数据。

所以下面这份阶梯是我构造的。

按生产流程学，你第一天就要同时面对分镜、生成、调色、混音——每一样都不会，每一样都在拖后腿。按能力难度学，一次只练一件事。

02 / 地基决定学习顺序的那条线

已验证 3-0VBench-2.0 区分 superficial faithfulness（逐帧美感、时序一致、基本 prompt 遵循——论文原话「approaching saturation」）与 intrinsic faithfulness（物理律、常识、解剖、构图完整）。关键是：intrinsic 不是全面失败，是特定维度崩溃。

Commonsense / Instance Preservation常识 · 物体保持
92–94%
Human Anatomy人体解剖
86–88%
Dynamic Spatial Relationship动态空间关系（走位、相对位置变化）
19–21%
Dynamic Attribute Change动态属性变化（边走边变色、逐渐融化）
8–24%
Complex Plot复杂情节
9–11%
vintage 警告：这批数字来自 VBench-2.0 Table II，对应 2025-03 那批模型（Sora / Kling / HunyuanVideo / CogVideoX）。不可当作当前值——当前榜单接口返回 401，取不到。用它判断「哪类维度难」，不要用它判断「今天某个模型多少分」。
模型已饱和逐帧美感、时序一致、基本 prompt 遵循、常识、物体保持——不是你的学习内容，别花时间。
模型崩溃动态空间关系、复杂情节、动态属性变化——这才是你的手艺所在，而且必须靠「改设计绕开」，不是靠「把 prompt 写得更好」。

这就是构造阶梯的原则，也是全文的方法核心。

03 / 阶梯七级，逐级打勾

我构造的地基是上一节的证据，编排是我的推论。点开每一级看判据、练习、卡点。勾选状态存在你自己的浏览器里。

进度
0 / 7
L0 看懂先长眼睛 · 3–5 小时
判据
给你一条 AI 片，能指出 ≥5 个破绽并说出成因（对照第 04 节的 12 个破绽）
练习
找 3 条 AI 短片 + 1 条专业实拍片，逐条对照 12 tells 打分，做成表格
工具
LibTV 的「逐帧拉片」把影视学院的拉片训练法产品化了；或任何播放器逐帧看
卡点
觉得「都挺好啊」——说明还没过关。看不出破绽，后面每一级的自检都是假的，所以这一级在最底层
L1 单镜头出片手感 · 1–2 天
判据
一条 5–10 秒片段，12 个破绽里 0 命中
练习
同一条 prompt 抽 10 次，逐条标注命中了哪几个破绽，做成表
工具
Seedance（BytePlus / 即梦 / LibTV，¥0.4 秒起）· 五段式提示词 · /shortfilm-prompt skill
卡点
以为是 prompt 写得不好——其实是选题落在了模型崩溃维度。想要「主角边走边变色」= dynamic attribute change，模型级得分 8–24%，换谁写都一样
L2 规避设计 ★分水岭 · 半天想清楚，之后一直用
判据
给定任一模型崩溃维度，能提出 ≥2 种在美术或叙事上绕开它的方案
练习
写一份约束清单：你想做的题材里哪些元素会踩崩溃维度？每条给一个绕法。
例：「两人对话走位」→ 动态空间关系仅 19–21% → 绕法 a) 改成静止对峙 b) 改成单人 + 画外音
工具
纸笔。这一级没有工具能替你做
卡点
习惯性想「再调调 prompt」。崩溃维度不是 prompt 能救的
示例
《丧尸清道夫》把主角设计成「机器人 + 像素表情屏」，不是美术偏好，是在模型崩溃维度上改需求。它是这一级的一个示例，不是这一级本身
L3 一致性工程3–5 天
判据
3+ 个镜头里同一角色 / 场景，人眼一眼认得出是同一个
练习
做一个 3 镜头连续片段，对比「只靠文字描述」vs「参考图条件化」的一致性差距
工具
参考图条件化（ingredients）· 每条 prompt 逐字重复角色描述 · 角色资产库
卡点
参考图质量不够。「图片质量不高就别喂参考图」——AI 会模仿画风而不是模仿设计
我的类比context engineering ↔ 资产工程这一轴，两轮研究零存活证据。唯一的机构级线索因验证器报错，既未证实也未证伪。
L4 管线与批量Claude Code 主场 · 3–5 天
判据
一条命令从 shots.yaml 跑到粗剪成片；某镜头失败能断点续跑
练习
批量出 20 条 + 每条自动落台账：prompt / 模型 / 参数 / seed / 抽第几次 / 花费 / 选没选中
工具
OpenMontage（48.9k★）· ViMax（12k★）· comfy-mcp · 自己写
卡点
照记忆写 SDK 调用。先 print(resp) dump 真实响应再写解析——各家 API 半年一变
我的类比harness 这一轴同样零存活证据——但 OpenMontage / ViMax 的存在是工程事实，已逐个核验。
L5 自动筛选全网空白 · 最值钱的自研点
判据
机器排出的 top 3 里，≥1 条是你人眼也会选的
练习
拿 L4 攒的台账——尤其「选没选中」那一列——训一个筛选器
工具
VBench（1.7k★ Apache-2.0）· VLM-as-judge 自己搭
方向
可引的替代路线：NeuS-V（把 prompt 转成时序逻辑规范做形式化验证，与人类评估相关性高出既有启发式 5 倍以上）· FiVE-Acc（VLM 做 Yes/No 语义询问）· Video-Bench 的 Chain-of-Query
这一级最容易踩的坑：模型级 eval ≠ 镜头级筛选。VBench-2.0 / AesRM 是给生成器排名的基准，拿来「筛我今天抽的 20 条」是超出设计意图的外推。而 FVD / CLIPScore 当筛选器在方法论上根本不成立——FVD 是分布级指标，对单条视频没有定义（属范畴不适用，不是「不准」）。
已被坐实的只有训练闭环（AesRM 用于对齐 Wan2.2-TI2V-5B 这个消费级小模型），「评估→选片」那一半没有被证明。
L6 非视觉维度学术界还没给出可测量分解
范围
剪辑节奏 · 色彩管理 / LUT · 声音设计 / 拟音 / 混音 · 叙事结构 · 表演
状态
两套学术 rubric（AesRM 15 细则、VBench-2.0 18 子能力）完全不覆盖这些，本轮零结论
怎么办
回传统影视教材。AI 没有改变这一半的学习方式
入口

04 / 检查表「一眼假」的 12 个破绽

学术表述是 superficial / intrinsic 之分，实操版是这 12 条。红边落在 intrinsic 一侧（物理 / 解剖，模型崩溃）黄边落在 superficial 一侧（后期可修）。两套框架对得上，互为印证。

01手部变形暂停数手指——4 根 / 6 根 / 帧间变化。绕：选不露手的镜头，或构图让手出画
02切镜后背景物理不一致云位置、阴影、光向在两镜间是否守恒。绕：人工控制多镜背景
03平板恐怖谷打光各环境都是「晴朗午后」扩散光、无硬阴影。修：显式给光位与硬阴影
04过饱和合成色草太绿、肤色偏橙、天空均匀饱和无渐变。修：后期压到真实传感器水平
05运动过于顺滑像飞行模拟器一样线性稳定，缺真实微抖。修：加微抖 = 五段式的「呼吸感」行
06口型音画不同步看 p / b / m 双唇音时嘴有没有闭合。修：调优的语音克隆
07镜面反射崩坏反射物错位、角度错、直接消失。绕：画面里别放镜面
08画面内文字变乱码路牌书封是否帧间一致可读。绕：场景里最小化文字
09背景群演单腿走路步态是否真的左-右-左。绕：剔除背景密集的镜头
10纹理重复平铺草地砖墙沙滩有无可见重复块。修：手动处理
11克隆声无呼吸真人每 5–10 秒换气一次，AI 常不换。修：带韵律模型的 TTS
12TTS 平台调有无重音起伏、列举加速、停顿。修：同上
来源是 opus.pro 的行业 blog（非学术），但每条都与 VBench-2.0 的 superficial / intrinsic 划分对得上。
