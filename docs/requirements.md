# requirements — Videoooo 需求三分法

> 三张清单：**已确认**（写死，AI 照做）/ **待拍板**（AI 不许替你决定）/ **暂停禁令**（未获明确指令前不实现）。
> 拍板即落盘：任何一条从「待拍板」挪到「已确认」，同批更新 `AGENTS.md` 相关表述与 `dashboard.html`。

## A. 已确认（2026-08-19 定档问答）

| # | 内容 |
|---|---|
| A1 | 项目性质 = **个人学习仓**：学 AI video，记学习笔记，跟着写相关代码。不是产品 |
| A2 | 交付物终局 = **本机自用工具**（这台 Mac 上跑，命令行为主） |
| A3 | 不碰钱 / 不碰真实用户数据 / 不对外服务 → 主车道 **Explore** |
| A4 | 时间尺度 = 持续迭代数周以上 → 档位 **M 标准**（不静默降档；变瘦要走 adopt §三，须你显式批准） |
| A5 | Python 包管理一律 `uv`，禁 pip（继承你的全局铁律） |
| A6 | 规划链（MRD/PRD/技术方案/autoplan）跳过 —— 学习仓无产品范围可写，已登记进 `agent-on.lock.md` local_deviations |

## B. 待拍板（等你 —— AI 不许自己选）

| # | 问题 | 为什么卡在你这 | 拍完解锁什么 |
|---|---|---|---|
| **Q1** | **第一条主线工具选哪个？** 云 API（Runway / Veo / Sora / Kling…）· 聚合平台（Replicate / fal）· 本地开源（ComfyUI + Wan/HunyuanVideo 等） | 三条路的学习曲线、花钱方式、硬件门槛完全不同。云 API 上手快但按次付费；本地免费但吃显卡、装环境能耗掉一整天 | 直接开 phase S0.1 |
| **Q2** | **学习重心偏哪边？** ①会用（提示词/工作流/出片质量） ②会调（API/参数/自动化管线） ③会改（模型原理/微调/自己训） | 决定笔记写什么、实验做多深 | 决定 S0.2 之后的里程碑排布 |
| **Q3** | **每月愿意在 API 上花多少？**（0 = 只跑本地开源） | 暂停项 P2 说了不自动调付费接口；有个额度我就不用每次都问 | 免掉反复确认，跑实验更顺 |
| **Q4** | **参照物**：有没有哪个人/频道/产品的 AI video 是你想做出来的样子？ | 品味前置——给个参照物比写十段描述省事 | 让笔记和实验对着一个具体目标走，而不是漫游 |

> 对 Q1 的一句建议（不是替你拍板）：若目的是**学写代码**（你说的重点），从**聚合平台**起步性价比最高——一套 API 能横着试多个模型，不用为每家单独接 SDK，也不用先跟显卡搏斗。等摸清了再决定要不要下本地。

## C. 暂停禁令（未获明确指令前不实现、不假设）

与 `AGENTS.md` §1 暂停项表同源，改一处两处同改：

| # | 禁令 | 解禁条件 |
|---|---|---|
| P1 | 不做产品化 / 不部署上线（无 Web 前端、无用户系统、无域名） | 你显式说「要给别人用」→ 同时走 adopt §二升 L 档 |
| P2 | 不自动调用付费 API | 每次调用前报预估花费问一句；或你在 Q3 给个月度额度 |
| P3 | 不碰真实用户数据 / 不采集第三方平台内容 | 你显式授权 + 升档 |
| P4 | 不引入重框架（Docker / K8s / 训练管线 / 自建模型服务） | 你点名 |
