# Phase P1 — 复刻一个镜头（先要手感）

> **为什么这张卡不写代码**：不知道抽卡是什么感觉，写出来的管线全是想当然。
> 《丧尸清道夫》作者 2026 年 2 月接触 AI、5 月成片爆红——**作品驱动，学习是副产品**。

## 0. 前置检查

- [ ] 已看完原片（[完整版](https://www.bilibili.com/video/BV1KJ5v67EQM/)），选定**一个**要复刻的镜头，写下选它的理由
- [ ] 已读 `docs/notes/02-shortfilm-method.md` 第一节（五段式）与第二节（三条反直觉原则）
- [ ] Seedance 入口已确认可用：HK 走 [BytePlus ModelArk](https://docs.byteplus.com/en/docs/ModelArk/1099455)，或先用[火山免费体验](https://exp.volcengine.com/ark/vision?launch=seedance)/即梦网页版试手

## 1. 验收标准

- [ ] **五段齐全**：核心主题（3–6 标签，含一个否定式）/ 人物设定（面部+服装质地+动态场景）/ 氛围画质（**具体摄影机型号**，禁「电影感/4K/高细节」）/ 运镜（含「呼吸感」行）/ 分镜（按秒或按镜切片，每段动作+镜头+特效三件套）
- [ ] **声音行写了**：`声音：无配乐，仅保留现场同期声`
- [ ] **瑕疵写了**：每段落 ≥2 处瑕疵，且「杜绝美化」写死——检查画面里有没有被 AI 磨皮
- [ ] **一个 clip 只给一个运镜**（叠加会不稳）——检查提示词里没有 dolly+pan+tilt 混写
- [ ] **抽到一条自己认可的**，并记下**抽了几次**（参考基线：简单镜头 2–3 次，难镜头 20+ 次）
- [ ] **台账起头**：每次生成记一行（prompt 版本 / 模型 / 参数 / 抽第几次 / 选没选中）——`选没选中`这一列以后是训练自动筛选的金矿
- [ ] **认知差 ≥1 条**：`docs/notes/03-p1-log.md` 写「我原以为 X，实际是 Y」
- [ ] **花费记录**：本卡实际消耗写进笔记（本轮调研证明网上单价大多不可靠，**你自己的账单是唯一可信数据**）

## 2. 内联要点

- **别用真人脸**：如果复刻的镜头有人脸，优先选无人脸/机器人镜头。一致性问题在**设计层**绕开，不在提示词层硬扛
- **图不够好就别喂参考图**：AI 会模仿画风而不是模仿设计
- **Seedance 时长陷阱**：豆包 App 锁死 5/10 秒预设，完整 4–15 秒只在即梦/Dreamina 网页版——先确认你要的档位拿不拿得到
- **版权词会被拦**：被毙了先换近义词，别怀疑提示词结构
- **结尾留白**：原片片尾「没有台词。没有爆炸。没有光芒万丈。」
- **扫坑指针**：动手前对照 `docs/notes/01-learning-path.md` §二 十条弯路清单
