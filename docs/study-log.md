## 反推法（不生成一帧的练法）

```
挑一个成片镜头（5-15 秒）
  → 对着 5-Aspect 五维反推它的分镜表
  → 填进 shots.yaml，跑校验器
  → 跟原片对照：我推的 vs 它实际呈现的，差在哪
```

梯度：**易**=静止或单一运镜 · **中**=主体运动+运镜（最常推错：分不清主体动还是镜头动）· **难**=多主体+景深变化+有 overlay
